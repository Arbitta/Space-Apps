# Recursos sintéticos heredados

El módulo `power.py` y `tests/data/samples/comodoro_rivadavia_2000_2024.json`
proceden de `origin/results-charts` (`e33c76d`). Se conservan exclusivamente para
ejecutar las siete pruebas del motor. Su documentación original usa la expresión
«recurso oficial», pero no establece procedencia NASA verificable y el módulo
incluye ajustes numéricos generados para otras ubicaciones.

Son fixtures de software; no representan una comprobación de observaciones ni de
tendencias reales. La aplicación no importa este módulo, no sirve este archivo y
no utiliza su proveedor ni su respaldo. La verificación científica de la interfaz
usa los JSON reales anteriores de `data/cache/power`.
