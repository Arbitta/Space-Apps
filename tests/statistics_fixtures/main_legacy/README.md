# Referencias del servidor anterior de main

Se conservan los archivos originales de `origin/main` ce9a1e2 como referencias
de migración. No son proveedores activos ni observaciones científicas verificadas.
Sus muestras y ajustes espaciales no se importan desde la aplicación Flask.

Las pruebas anteriores de Time Machine y auditoría exigían el servidor
`EarthLensUnifiedHandler`, respuestas HTTP sin sobre y generación de series al
redimensionar cuadrantes. Sus precondiciones contradicen el contrato vigente y
la prohibición de crear observaciones. Se conservan con sufijo `_reference.py`;
no se presentan como pruebas aprobadas de la aplicación integrada.

La regresión del backend conserva sus pruebas originales. El contrato integrado
de Time Machine se verifica en `tests/test_time_machine.py`, con respuestas
simuladas explícitas y cachés temporales. Las comprobaciones reales usan las
cachés locales, red bloqueada y datos del catálogo argentino.
